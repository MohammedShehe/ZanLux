# ZanLux public website (HTML + CSS + JS + Bootstrap 5)

1. In `js/config.js` set the API URL (same FBBMS backend, ends with `/api`). `SLUG` must match the business slug (`zanlux`).
2. Upload to `zanlux.online` (a `CNAME` is included for GitHub Pages).
3. Products, prices, photos, stock, texts, contact details and the founder section all come live from FBBMS:
   * Management app → Products → switch on **Show on website**.
   * Management app → Shop & website → edit hero text, about, founder, contact, announcement bar.
4. Customer orders arrive instantly in **Website orders** (sound + notification). Mark Contacted → Confirmed → **Complete & record sale**
   (this is what adds the money to income and deducts stock).
